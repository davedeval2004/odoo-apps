How It Works

From question to answer in seconds

No technical knowledge required. Any Odoo user can get expert guidance instantly.



1

Click the "?" Button in the Systray

The Help button lives in the Odoo top navigation bar. Click it from any screen — a smooth chat panel slides up immediately. No page reload, no new tabs.

2

Type Your Question or Attach a Screenshot

Ask anything: "Why can't I confirm my invoice?", "How do I create a vendor bill?". Optionally attach a screenshot of any Odoo error or form using the paperclip icon for visual AI analysis.

3

AI Analyses and Responds

The configured AI (OpenAI, Anthropic, or OpenRouter) processes the question and any attached image. It follows a strict business-focused prompt purpose-built for Odoo workflows.

4

Follow the Step-by-Step Guidance

The response always includes: a plain-English explanation of the issue, numbered navigation steps (e.g. Sales › Orders › Quotations), the business reason behind it, and a prevention tip.

5

Continue the Conversation

Ask follow-up questions in the same session — the AI remembers full conversation context. Start a new session with the "+" button, or clear history with the trash icon at any time.

Configuration

Up and running in under 2 minutes

Go to Settings → General Settings → Help Chatbot and fill in four fields.



Setting Description Example Value
AI Provider Select between OpenAI, Anthropic, or OpenRouter openrouter
API Key The API key from your chosen provider — stored securely as a system parameter sk-••••••••••••
Model Name The specific AI model to call — must match your provider's model identifier exactly openai/gpt-4o
Max Response Tokens Limits the length of AI responses — higher means more detail and slightly more API cost 1024

Only users in the System Administrator group can access and modify Help Chatbot settings. All API keys are stored as encrypted Odoo system parameters.
