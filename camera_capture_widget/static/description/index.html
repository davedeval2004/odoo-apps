Web Camera Widget

Capture images directly from your device's camera inside any Odoo form view. No plugins, no extra software.

Odoo 19 All Browsers Desktop & Mobile

Overview

The Web Camera Widget module adds a camera capture button to any image field in Odoo 19. Click the camera icon, grant permission, snap a photo — and it's saved directly to the record. Perfect for employee photos, product images, quality inspection captures, and more.

Key Features

📷
One-Click Capture Camera button appears on any image field. Click, snap, done.
🔄
Front / Rear Camera Toggle between front and rear cameras on mobile devices with a single tap.
✅
Review Before Save Preview your capture and retake if needed before confirming the image.
🌐
Cross-Platform Works on Chrome, Firefox, Safari, Edge, iOS, Android, Linux, and Windows.

How to Use

1
 Install the Module Install camera_capture_widget from Apps. No extra configuration needed.
2
 Add the Widget to a Field Use widget="camera" on any Binary/Image field in your form view XML.
3
 Capture Photos Click the camera icon on the image field, allow camera access, capture your photo, and confirm.

XML Usage Example

<field name="image_1920" widget="camera"/>
